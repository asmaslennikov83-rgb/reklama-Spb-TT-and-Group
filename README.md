# WB Ads Telegram Bot

Telegram-бот для мониторинга рекламных кампаний Wildberries по официальному WB API.

## Что умеет

- До 2 кабинетов Wildberries.
- API-токены добавляются/обновляются через Telegram.
- Название кабинета определяется автоматически через WB Seller Info.
- Автоматически отслеживаются все рекламные кампании.
- Проверка по умолчанию каждые 15 минут.
- Интервал меняется прямо в Telegram (1–1440 минут).
- Уведомление один раз при падении активной кампании до 300 ₽.
- При балансе <=100 ₽ уведомление приходит при каждой проверке.
- После пополнения выше 300 ₽ порог 300 ₽ снова активируется.
- Уведомления о новой кампании.
- Уведомления о паузе/остановке.
- Уведомления о завершении/отмене.
- Уведомления о возобновлении.
- Уведомление об ошибке WB API и отдельное сообщение после восстановления.
- `/status`: только общее количество и количество запущенных кампаний по каждому кабинету.
- Меню: статус, кабинеты, ручная проверка, интервал, последние события.
- Состояние хранится в SQLite и переживает перезапуск.
- WB API-токены хранятся в SQLite в зашифрованном виде.

## Как запустить

### 1. Создайте Telegram-бота
В Telegram откройте @BotFather, выполните `/newbot` и получите токен.

### 2. Настройте окружение
Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните:
- `BOT_TOKEN`
- `BIND_CODE`
- `APP_SECRET`

`APP_SECRET` и `BIND_CODE` должны быть длинными случайными строками.

### 3. Установите зависимости

Python 3.11+:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### 4. Привяжите Telegram
Напишите своему боту:

```text
/bind ВАШ_BIND_CODE
```

После успешной привязки бот принимает команды только от этого Telegram-пользователя.

### 5. Добавьте кабинеты WB
Откройте:
`/start` → `➕ Добавить кабинет`

Отправьте токен категории **Продвижение**. Бот:
1. удалит сообщение с токеном, если Telegram позволит;
2. проверит токен;
3. получит название продавца автоматически;
4. проверит доступ к Promotion API;
5. зашифрует токен перед записью в SQLite.

Можно добавить максимум два разных кабинета.

## Логика уведомлений

### 300 ₽
Если активная кампания впервые становится <=300 ₽ и при этом >100 ₽:

```text
🟡 Баланс рекламы ниже 300 ₽
Кампания: Название кампании
Кабинет: ООО Пример
Баланс: 284 ₽
```

Повторно это предупреждение не приходит, пока бюджет не пополнят выше 300 ₽.

### 100 ₽
Если активная кампания имеет <=100 ₽:

```text
🔴 КРИТИЧЕСКИЙ БАЛАНС РЕКЛАМЫ
Кампания: Название кампании
Кабинет: ООО Пример
Баланс: 87 ₽
```

Это сообщение приходит при **каждой проверке**, пока баланс <=100 ₽.

### Новая кампания
При первом подключении кабинета уже существующие кампании синхронизируются без десятков уведомлений.
Все кампании, созданные после этого, вызывают уведомление `🆕 Новая рекламная кампания`.

### Статусы
- `9` — активна
- `11` — на паузе → уведомление об остановке
- `7` — завершена → уведомление
- `8` — отменена → уведомление
- переход обратно в `9` → уведомление о возобновлении

## Важное для хостинга

Бот использует Telegram Long Polling, поэтому подойдёт хостинг, где Python-процесс может работать постоянно.

Обязательно обеспечьте **постоянное хранилище** для `wb_ads_bot.db`. Если хостинг стирает файловую систему при каждом деплое, подключите persistent disk / volume и задайте `DB_PATH` на нём.

Не выкладывайте `.env`, `BOT_TOKEN`, `BIND_CODE`, `APP_SECRET` и WB API-токены в GitHub.

## Docker

В комплекте есть `Dockerfile`.

```bash
docker build -t wb-ads-bot .
docker run -d \
  --name wb-ads-bot \
  --restart unless-stopped \
  --env-file .env \
  -v "$(pwd)/data:/app/data" \
  -e DB_PATH=/app/data/wb_ads_bot.db \
  wb-ads-bot
```

## Используемые официальные методы WB API

- `GET https://common-api.wildberries.ru/api/v1/seller-info`
- `GET https://advert-api.wildberries.ru/adv/v1/promotion/count`
- `GET https://advert-api.wildberries.ru/api/advert/v2/adverts`
- `GET https://advert-api.wildberries.ru/adv/v1/budget`

Проверка бюджетов выполняется с задержкой между запросами, чтобы соблюдать лимит метода бюджета.

## Примечание

WB периодически меняет API. Если в будущем изменятся поля или URL методов, достаточно обновить класс `WBClient` и `parse_campaign()` в `main.py`.
